## 4. Code-audit conclusions (area → verdict)

- **Payments**: amounts always server-side from stored order totals; ownership check on
  create/verify; Razorpay verification = gateway fetch (authoritative, amount + order_id match)
  with HMAC signature fallback; confirm pipeline idempotent; amount mismatch REJECTED;
  webhook HMAC over raw body + unique-event dedupe (replay-safe) + 500-on-error for retries;
  refunds via provider; no card data ever touches server. TEST provider hard-gated out of
  production; new prefix guard closes the test-keys-in-prod hole. COD independent of gateway ✅
- **Checkout/pricing**: integer paise math, tax-inclusive GST extraction, coupons re-validated
  inside the creation transaction with atomic usage limits, snapshots frozen on order items,
  atomic stock decrement, idempotencyKey + converted-cart dedupe ✅
- **Supplier layer**: adapter registry (MANUAL / HTTP_REST / DEMO); DEMO hard-gated out of
  production (falls back to MANUAL queue, honestly); HTTP_REST is config-driven (endpoints,
  status maps, auth via env-var NAMES only), Idempotency-Key header on createOrder,
  api_logs for every call, fulfilment job dedupe key `so_{orderId}_{supplierId}` (no duplicate
  supplier orders on retry) ✅. No real supplier configured yet ⇒ automated fulfilment NOT live.
- **Auth/session**: bcrypt, httpOnly+Lax+Secure(in prod) session cookie, purge job, login
  throttling per-IP (20/15min) + per-account (8/15min), password reset no-enumeration ✅
- **Admin/authz**: requireStaff/requireAdmin/assertOwnerOrAdmin on routes; E2E admin-authz 11/11 ✅
- **Email**: console|smtp abstraction, credentials env-only; console = logs only (not a real
  delivery service) ⇒ real provider required before launch communications matter.
- **Cron**: single endpoint `POST /api/cron/jobs`, `Authorization: Bearer <CRON_SECRET>`,
  processes due jobs + purges sessions/abandoned carts; recommended every 5 min.
- **Storage/uploads**: magic-byte validation, 5 MB cap, random names, admin-only, nosniff —
  but persistence = local disk ⇒ ephemeral on Vercel (decision item, notice added to admin UI).
- **SEO/UX**: metadataBase from APP_URL, per-page metadata + canonicals, robots/sitemap,
  error.tsx/global-error/not-found, demo/TEST banners everywhere test mode is visible ✅
- **Policies**: privacy/terms/shipping/returns pages exist, content driven by Admin→Settings
  values (return window, cancellation window…) — facts must be set/verified by owner.
